## How to Search Within a File on GitHub

1. Open the file on GitHub
2. Press **Ctrl+F** (Windows) or **Cmd+F** (Mac)
3. Type the section name or keyword
4. GitHub will highlight matching lines

**Useful search terms:**
- `tab1`, `tab2`, ... `tab17` → find each tab section
- `initApp` → find app startup code
- `calculateAndRenderMaterials` → find the estimate calculation engine
- `INVENTORY_DB` → find the product catalog (61 SKUs)
- `validateStep` → find form validation
- `switchTab` → find tab navigation logic
- `localStorage` → find data persistence
