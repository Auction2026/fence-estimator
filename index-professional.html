📖 Project Tab – Step-by-Step Guide

  1. Enter the customer's full name and contact details.
  2. Enter the complete project (installation) address including city, province, and postal code.
  3. Select the project type (Residential or Commercial).
  4. Add any special access instructions or notes that the crew will need on site.
  5. Click Save Project — this populates the customer name in all other tabs and documents.
Project & Customer Information
Enter customer contact details and project information — this data populates all other tabs and documents.

📖 Fence Style Tab – Step-by-Step Guide

  1. Select the Fence Type (Chain Link, Wood, Vinyl, or Wrought Iron).
  2. Choose the Fence Height — only heights appropriate for the selected type apply.
  3. Select the Style/Pattern (Privacy, Semi-Privacy, Picket, etc.).
  4. Choose the Color/Material Finish from the dropdown.
  5. Enter the number and width of gates required.
  6. Choose post spacing — 6 ft is standard for residential chain link.
  7. Click Save Fence Style to lock in the selections for this project.

📖 Installation Tab – Step-by-Step Guide

  1. Enter the planned Start Date and Completion Date for the installation.
  2. Select the Crew Size — this adjusts the labour calculation multipliers automatically.
  3. Enter total Linear Footage to be installed.
  4. Indicate the Terrain Conditions and Soil Type — these affect post-hole drilling times and concrete requirements.
  5. Specify any Special Installation Notes (e.g., concrete slope, rocky ground, existing fence removal required).
  6. Click Save Installation Details before proceeding to the Estimate tab.
Installation Details
Specify installation requirements, timeline, and conditions
All installations must comply with Canadian Standards (CAN/CGSB-138.3-2019, CSA standards, and local building codes)

📖 Permit Tab – Step-by-Step Guide

  1. Enter the Municipality where the fence will be installed.
  2. Select the Province/Region — this loads the applicable building code standards.
  3. Indicate whether a permit is Required for this fence (most fences over 6 ft or near property lines require one).
  4. Fill in the permit application number once obtained.
  5. Use the checkboxes to select which permit forms to print or email to the customer.
  6. Click Save Permit Info to record all permit details for this project.
Permit Information
Track permit requirements and compliance with building codes

📖 Locates Tab – Step-by-Step Guide

  1. MANDATORY: Call 811 or Ontario One Call BEFORE any digging. This is a legal requirement.
  2. Select whether a locate request has been submitted and which service was used.
  3. Record the Locate Reference Number — this is your proof of compliance.
  4. Enter the Locate Request Date and expected confirmation date (typically 3 business days).
  5. After locates are complete, document any utilities found on the property.
  6. The locate status is passed to the Installer Work Paper so the crew knows it's safe to dig.
Utility Locates
Track utility line locating (Ontario One Call, 811, etc.)
SAFETY CRITICAL: Before ANY digging: Call 811 (Canada) or Ontario One Call (Ontario) for FREE utility location services. This is MANDATORY and protects against electrocution, gas leaks, and water damage.

📖 Estimate Tab – Step-by-Step Guide

  1. Enter the Total Linear Footage — the number of posts is auto-calculated using the post spacing from Fence Style tab.
  2. Enter the Labour Rate per Hour (include wage, WCB, and overhead).
  3. Enter costs for Materials, Hardware/Fasteners, and Concrete separately.
  4. Use the Concrete Calculator below to calculate exact concrete needed for your post holes.
  5. Enter any Extra Work costs (gate operators, removal of old fence, etc.).
  6. Set Overhead % and Profit Margin % to match company policy (admin sets defaults).
  7. Click Calculate Estimate to generate the full cost breakdown.
  8. Use the Estimator Round-Up to adjust the final price to a clean number.
  9. Once the estimate becomes a contract, pricing is locked — no price changes affect the locked contract.

📖 Extras Tab – Step-by-Step Guide

  1. Select any additional items that are part of this project but not part of the standard fence installation.
  2. For Barbed Wire: enter the number of strands and total footage.
  3. For Electric Gate Operators: select the gate type (swing, slide, cantilever) and operator model.
  4. For Bollards: enter the number and type (fixed, removable, decorative).
  5. For Decorative Inserts: select the insert type and enter the square footage.
  6. For Barrier/Crash Gates: select the style and enter gate width.
  7. All extras are automatically added to the Estimate total and itemized in the Contract.

📖 Breakdown Tab – Step-by-Step Guide

  1. Select the Fence Type to see the step-by-step calculation methodology for that specific fence.
  2. Enter the Linear Footage and number of posts/gates to see a live breakdown.
  3. Each step shows the formula, calculated value, and the PLU numbers of materials required.
  4. Use this tab to verify the auto-calculated estimate or to train new estimators.
  5. The Breakdown view reflects the current estimate values automatically when you click "Generate Breakdown".

📖 Contract Tab – Step-by-Step Guide

  1. Select the Contract Template appropriate for the job (Residential, Commercial, or Custom).
  2. Review the Payment Terms, Warranties, and all legal clauses — these are admin-controlled and cannot be changed by estimators.
  3. Click Generate Contract to produce the PDF contract with all project and pricing details filled in.
  4. Click Send to Customer to email the contract for review and e-signature.
  5. Once the customer signs, click Mark as Signed — this LOCKS the pricing. Any future price changes will NOT affect this contract.
  6. A 🔒 Locked badge will appear confirming the pricing is frozen.

📖 Shop Drawings Tab – Step-by-Step Guide

  1. The Site Address is auto-populated from the Project tab.
  2. Enter the overall Site Dimensions (e.g., 100' × 50') or property lot size.
  3. In the Site Layout, describe or sketch the fence line: start/end points, corners, gates, obstacles, and utility locations.
  4. Enter the exact fence line details — linear footage, post count, and gate count.
  5. Add any Shop Drawing Notes for the fabrication shop (e.g., gate frame dimensions, post heights above grade, etc.).
  6. Use the Property Mapping tab (Tab 17) for a visual map with fence lines drawn on it.
  7. Click Generate Shop Drawing to produce a printable/emailable drawing PDF.

📖 Installer Work Paper – Step-by-Step Guide

  1. Customer and address fields are auto-populated from the Project tab.
  2. Enter the Work Date and crew information for today's work.
  3. Check off the Tools & Equipment taken to the job site.
  4. Use the Daily Work Log to record start/end times (hours auto-calculate).
  5. Check the Tasks Completed checkboxes to track progress.
  6. Update the Project Completion % slider at end of day.
  7. For any issues or changes from original plan, use the Change Orders tab (Tab 12).
  8. When job is done: go to the Sign-Off tab (Tab 13) to get customer approval.
  9. Click Save Work Log to record today's activities, then Print Work Paper for the crew.

📖 Change Orders Tab – Step-by-Step Guide

  1. Use this tab whenever the customer requests changes from the original contract.
  2. Describe the requested change, the reason, and the impact on materials/labour.
  3. Enter the additional cost (positive) or credit (negative) for the change.
  4. Have the customer sign the change order before proceeding with the modified work.
  5. A change order is legally required to modify a locked contract — the original contract pricing remains intact.
  6. Each change order is numbered automatically and linked to the project.
Change Orders
Document and manage all changes from the original contract scope
All changes to a signed contract require a signed change order. Obtain customer signature before proceeding with any modified work.

📖 Sign-Off Tab – Step-by-Step Guide

  1. Complete this tab at the job site with the customer present when the installation is finished.
  2. Walk the customer through the completed work and confirm all items from the contract are done.
  3. Go through the Final Inspection Checklist item by item.
  4. Have the customer provide their printed name and confirm satisfaction.
  5. Click Mark Job Complete to finalize the project — this triggers the final invoice.
  6. Print or email the sign-off document as the customer's completion record and warranty start document.

📖 Admin Panel – Step-by-Step Guide

  1. This panel is for Admin users only. Estimators cannot access or modify these settings.
  2. Set Installation Rates: per-foot fence rate, per-post rates, gate rates, and gate operator rates.
  3. Set Labour Rates: hourly rates for Foreman, Labourer, and Equipment Operator.
  4. Configure Equipment Costs: daily/hourly rental for backhoe, skidsteer, excavator, and attachments.
  5. Set Specialty Costs: tipping fees, concrete per hole, stone dust per hole.
  6. Update Company Legal Terms: scope of work template, payment terms, warranties, liabilities, and all contract clauses.
  7. Click Save Settings to apply changes. Changes affect new estimates only — existing locked contracts are not affected.
