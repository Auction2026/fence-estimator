# Viewing Guide

This guide is for quickly finding the code without searching around the repository.

## Step 1: Start Here

Open [README.md](./README.md)

## Step 2: Choose What You Want to View

### If you want the main app code
Open [index.html](./index.html)

What is inside:
- HTML layout
- CSS styles
- JavaScript logic
- Inventory data
- Estimate wizard code

### If you want the professional app version
Open [index-professional.html](./index-professional.html)

What is inside:
- Professional UI layout
- Tab content
- Styling
- JavaScript tab switching

### If you want the material/reference data
Open these files:
- [FENCE_MATERIAL_SPECIFICATIONS.md](./FENCE_MATERIAL_SPECIFICATIONS.md)
- [MEGA_RESEARCH_SESSION_LOG.md](./MEGA_RESEARCH_SESSION_LOG.md)
- [BACKUP_LOG.md](./BACKUP_LOG.md)

## Step 4: Easiest Path for Most Users

If you only want the main coding:
1. Click [index.html](./index.html)
2. Scroll through the file
3. Use your browser search for these terms:
   - `<style>` for CSS
   - `<body>` for page layout
   - `<script>` for JavaScript
   - `INVENTORY_DB` for product data
   - `switchTab` for tab logic
