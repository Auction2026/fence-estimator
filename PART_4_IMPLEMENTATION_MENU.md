# PART 4 IMPLEMENTATION MENU

1. Install backend dependencies: `cd backend && npm install`.
2. Start backend API: `npm run dev`.
3. Initialize database with `database/schema.sql` then `database/seed.sql`.
4. Run migration scripts in `database/migrations` in ascending order.
5. Serve frontend from repository root using `npm start`.
6. Validate app flow across all 17 tabs and save/export paths.
