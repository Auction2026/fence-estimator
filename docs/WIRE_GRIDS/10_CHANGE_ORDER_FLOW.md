WHAT IS A CHANGE ORDER?
═══════════════════════
A Change Order (CO) is a written modification to the original
contract. It documents any change in scope, price, or timeline
AFTER the original contract is signed and locked.

WHEN IS A CHANGE ORDER NEEDED?
════════════════════════════════
  ✅ Customer wants to add more fence footage
  ✅ Customer wants to upgrade materials (e.g., black instead of galv)
  ✅ Customer wants to add a gate not in original scope
  ✅ Site conditions require extra work (rocky ground, tree removal)
  ✅ Customer wants to change fence type or height
  ✅ ANY other change that affects cost or scope

## ✅ CHANGE ORDER BEST PRACTICES

| Do This | Don't Do This |
|---------|---------------|
| Create CO BEFORE doing the work | Do extra work without written CO |
| Get customer signature | Rely on verbal agreement |
| Print a copy for customer | Only keep digital copy |
| Note exactly what changes | Write vague descriptions |
| Price out the change accurately | Estimate without looking up prices |
