
# Calculation Flow

```text
Fence Type + Height + Footage
            |
            v
Determine Material Quantities
(posts, panels, rails, gates, concrete, hardware)
            |
            v
Look Up Unit Prices in Catalog
            |
            v
Material Cost
            |
            +-----------------------------+
            |                             |
            v                             v
      Labor Inputs                 Permit / Utility / Extras
(installation type, crew, rate)          costs
            |                             |
            v                             |
         Labor Cost                       |
            |                             |
            +-------------+---------------+
                          |
                          v
                     Subtotal
                          |
                          v
                    + Overhead %
                          |
                          v
                     + Markup %
                          |
                          v
                       + Tax %
                          |
                          v
                    Total Estimate
```

## Practical interpretation
- **Fence Specs** define what must be built.
- **Layout** defines how much must be built.
- **Catalog** defines what each component costs.
- **Installation and crew settings** define labor cost.
- **Overhead, markup, and tax** convert raw cost into the sell price.
