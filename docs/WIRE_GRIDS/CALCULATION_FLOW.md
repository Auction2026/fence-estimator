# Calculation Flow

## Overview
Pricing is built by converting measurements and fence selections into quantities, costs, tax, and customer totals.

## ASCII Diagram
```text
Linear Feet + Height + Fence Type
             ↓
Post Count / Panel Count / Gate Count
             ↓
Material Cost + Labor Cost + Equipment + Concrete + Permit + Contingency
             ↓
Subtotal → Tax Rate → Tax Amount → Total Amount
```
