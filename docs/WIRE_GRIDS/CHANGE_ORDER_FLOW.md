
# Change Order Flow

```text
Identify change needed
      |
      v
Create Change Order
      |
      v
Describe change + cost impact + schedule impact
      |
      v
Submit for approval
      |
      v
Manager reviews
   |                |
   |                |
   v                v
Rejected         Approved
   |                |
   |                v
   |          Update project total
   |          Add approved delta to contract history
   |          Notify customer
   |                |
   +----------------+
            |
            v
Record final status and audit trail
```

## Key rule
No post-lock price change should bypass the change-order record, approval, and customer notification trail.
