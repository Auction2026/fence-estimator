# Change Order Flow

## Overview
Change orders capture approved scope adjustments after a contract has already been created.

## ASCII Diagram
```text
Field Discovery / Customer Request
               ↓
Create Change Order Draft → Price Impact → Customer Review
               ↓                         ↓
          Rejected                Approved + Signature
                                         ↓
                                Implement in Active Project
```
