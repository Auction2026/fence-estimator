# Data Flow Diagram

## Overview
This wire grid shows how customer data moves from lead intake to pricing, contracting, installation, and sign-off.

## ASCII Diagram
```text
Lead Form → Customer Profile → Property Details → Fence Specs
          ↓                                     ↓
       Notes / Tags                        Material Catalog
          ↓                                     ↓
     Pricing Calculator → Estimate Builder → Contract Builder
                                           ↓
                                  Change Orders / Scheduling
                                           ↓
                               Installation Notes / Photos
                                           ↓
                                      Project Sign-Off
```
