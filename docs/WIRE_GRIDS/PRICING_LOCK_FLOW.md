# Pricing Lock Flow

## Overview
Price locking ensures accepted contracts remain stable even if inventory costs or retail rates change later.

## ASCII Diagram
```text
Inventory Update → New Estimate Uses New Prices
         ↓
Accepted Estimate → Contract Created → price_locked = true
         ↓
Change Order Needed? → yes → Add delta only
                     → no  → Keep original contract pricing
```
