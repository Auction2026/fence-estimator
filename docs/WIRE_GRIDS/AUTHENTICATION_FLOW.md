# Authentication Flow

## Overview
Authentication determines who can view, edit, approve, and close projects across the application.

## ASCII Diagram
```text
Login Form → /api/auth/login → JWT Issued → Browser Storage
       ↓                                 ↓
Failed Login ← Auth Middleware ← Protected API Request
                                          ↓
                                  Role-Based Access Check
```
