# User Workflow

## Overview
This workflow focuses on what the estimator, installer, and manager do in sequence while moving one project through the system.

## ASCII Diagram
```text
Estimator Login → Lead Entry → Measure Site → Price Fence → Send Estimate
                                               ↓
Manager Review ← Contract Approval ← Customer Acceptance
                                               ↓
Installer Schedule → Field Notes → Completion Photos → Sign-Off
```
