
# Database Schema Summary

The database package contains nine primary tables:

1. `users`
2. `customers`
3. `projects`
4. `fence_specifications`
5. `layout_segments`
6. `estimates`
7. `contracts`
8. `change_orders`
9. `catalog_products`

The schema file also includes indexes for status and relationship lookups plus update triggers for key transactional tables.
