# PART 4: Implementation Menu

## Step 1 - Install prerequisites
- Node.js 20+
- PostgreSQL 15+

## Step 2 - Backend setup
1. `cd backend`
2. `npm install`
3. Copy `.env.example` to `.env`
4. Update DB and JWT values

## Step 3 - Database setup
1. Create database `fence_estimator`
2. Run `database/schema.sql`
3. Run `database/seed.sql`

## Step 4 - Frontend setup
1. `cd frontend`
2. `npm run start`
3. Open `http://localhost:4173`

## Step 5 - Start API
1. `cd backend`
2. `npm start`

## Step 6 - Smoke test
- Open frontend tab flow
- Save a sample project
- Confirm estimate endpoint returns data
