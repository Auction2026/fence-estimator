# Part 1 - Main Estimator App

## Open This File

👉 [index.html](../index.html)

## What You Will See

`index.html` is the main code file in this repository.

It contains:
- Page structure (HTML)
- Styling (CSS)
- Application logic (JavaScript)
- Estimate wizard behavior
- Inventory and pricing data

## Easiest Way to Browse It

Use search in GitHub or your browser and look for:
- `<style>` - CSS section
- `<body>` - page layout section
- `<script>` - JavaScript section
- `INVENTORY_DB` - inventory data
- `switchTab` - tab changing logic
- `nextStep` - estimate wizard step logic
