# Fence Depot Estimator Setup Guide

## Essential commands
```bash
git clone https://github.com/Auction2026/fence-estimator.git
cd fence-estimator
```
```bash
cd backend && npm install
cd ../frontend && npm install
```
```bash
psql -h localhost -U fence_user -d fence_estimator -f database/schema.sql
psql -h localhost -U fence_user -d fence_estimator -f database/seed.sql
```
```bash
cd backend && npm start
cd frontend && npm start
```

- Install Node.js from nodejs.org.
- Install PostgreSQL from postgresql.org/download.
- Create database fence_estimator.
- Create database user fence_user.
- Copy backend/.env.example to backend/.env.
- Set JWT secret and database credentials.
- Open http://localhost:3001 after services start.
