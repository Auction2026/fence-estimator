# Fence Depot Estimator Viewing Guide

This simple guide explains how to open the application, where to begin, and how to move through the 17 tabs efficiently.

## Open the application
1. Start the backend service.
2. Start the frontend service.
3. Open a browser to http://localhost:3001.
4. Sign in with your account.
5. Wait for the Dashboard to load.

## Which tab should you start with?
- New user: start on **Dashboard** to see overall activity.
- New customer estimate: start on **Leads** and then **Customer Profile**.
- Existing project update: start on **Dashboard** or **Reports & Admin** and search for the project.

## How to create your first estimate
1. Create or open a lead.
2. Enter customer and site information.
3. Measure the property and sketch the layout.
4. Choose fence specifications and material grade.
5. Review the material catalog.
6. Run the pricing calculator.
7. Generate the estimate and review totals.
8. Share or convert the estimate into a contract.
