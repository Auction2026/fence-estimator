# Viewing Guide – How to Open and Use the Application

## Option 1: Open Directly (Quickest – No Backend)

1. Navigate to the `frontend/` folder in your file explorer
2. Double-click `index.html`
3. The application opens in your browser
4. All 17 tabs work with local storage (no backend needed for basic use)
5. Product catalog shows 950+ built-in products

**Note:** Without backend, data is saved in your browser only (localStorage).

## Typical Workflow (5 Steps)

1. **Tab 1** → Enter customer info and address
2. **Tab 2** → Select fence type, height, and linear footage
3. **Tab 8** → Click "Calculate Estimate" → review costs
4. **Tab 9** → Review contract → both parties sign
5. **Tab 13** → Complete project sign-off

---

## Offline Capability

The application works offline:
- All calculations run in the browser (no internet needed)
- Data auto-saves to browser localStorage every 30 seconds
- 950+ products are built into the JavaScript
- Maps require internet + Google Maps API key

---

## Printing

While on any tab, press **Ctrl+P** (or **Cmd+P** on Mac) to print.
Print styles are optimized for letter paper.
