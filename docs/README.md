# Fence Depot Estimator Documentation

Fence Depot Estimator is a fencing company estimation tool for tracking customers, projects, fence specifications, materials, pricing, estimates, contracts, change orders, installation notes, and project closeout.

## Features
- Dashboard
- Leads
- Customer Profile
- Property Details
- Site Measurement
- Fence Layout
- Fence Specifications
- Material Catalog
- Pricing Calculator
- Estimate Builder
- Contract Builder
- Scheduling
- Change Orders
- Installation Notes
- Photos & Documents
- Project Sign-Off
- Reports & Admin

## Technology Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js and Express.js
- Database: PostgreSQL 14+
- Authentication: JWT
- Documentation: Markdown and SQL
- Version Control: Git and GitHub

## Quick Start
```bash
git clone https://github.com/Auction2026/fence-estimator.git
cd fence-estimator
cd backend && npm install
cd ../frontend && npm install
psql -h localhost -U fence_user -d fence_estimator -f database/schema.sql
psql -h localhost -U fence_user -d fence_estimator -f database/seed.sql
```
