# Fence Estimator Delivery Package

This repository now contains an organized delivery package with:

- `backend/` for the HTTP API, controllers, models, middleware, and calculation utilities
- `frontend/` for the HTML/CSS/JavaScript workspace with 17 estimator workflow tabs
- `database/` for schema, migration, seed, and backup scripts
- `docs/` for implementation, API, troubleshooting, and schema references

## Quick start
```bash
npm start
```

Then open `http://localhost:3000`.

## Tests
```bash
npm test
```

## Legacy files
The original `index.html` and `index-professional.html` remain in place for comparison and reference while the new organized package lives in the directories above.
