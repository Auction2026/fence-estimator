# Fence Estimator

This repository now contains:
- `backend/` Express API service.
- Frontend delivery (`index.html`, `css/`, `js/`) with 17 tabs.
- `database/` schema, seed, migrations, and procedures.
- Implementation and troubleshooting docs.
- `docs/WIRE_GRIDS/` flow diagrams.

## Quick start
1. `cd backend && npm install && npm run dev`
2. In repo root: `npm start`
3. Open `http://localhost:8080`
