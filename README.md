# Fence Depot Fence Estimator

## Project overview
This repository now contains a baseline full-stack implementation with backend, frontend, and database assets for the 17-tab estimator workflow.

## Quick start
1. Backend: `cd backend && npm install && cp .env.example .env && npm run dev`
2. Frontend: `cd frontend && npm install && npm start`
3. Database: apply `/database/schema.sql` then `/database/seed.sql`.
